# web

This directory contains the frontend web application and supporting assets for the project.

## Directory

| Route | Purpose |
| --- | --- |
| `static/` | Contains CSS, image files, external libraries, and internal libraries |
| `templates/` | Main application HTML code for pages |
| `api.py` | API |
| `index.py` | Web Server |
## Notes

- This directory is intended for browser-facing code and UI-related assets.
- Keep app-specific logic organized by feature or responsibility.
